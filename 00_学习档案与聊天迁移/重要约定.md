# 重要约定

## 2026-10-19：学习系统重启

- 以当前 Git 仓库作为学习记录和 AI 协作上下文的唯一长期来源。
- 旧 Hexo 静态站点作为历史档案保留，不在没有源文章的情况下盲目重建。
- 新学习内容先以结构化 Markdown 记录，使内容与账号、设备和单一工具解耦。
- 账号迁移依赖 Git 仓库中的持久摘要，不假设聊天平台能导出或恢复全部历史。

## 2026-10-19：LeetCode 每日一题

- 周一到周五每天 1 题，周末休息。周一、周二、周四为新题，周三和周五重做旧题。
- “做过”以 2026-10-19 启动本计划前的全部 LeetCode 历史完成记录为准，而不是以本计划生成的记录为准。历史做过的题属于复习题；历史从未做过的题才属于新题。
- 历史状态与本计划完成状态分开记录。历史状态未确认的题不能默认归为新题或复习题；没有合格候选时保留“待选题”，向用户确认或导入历史记录后再安排。
- 首先校准并完成热题 100 的 68 道中等题。
- Markdown 题解仅记录题目、核心思路、代码、复杂度和易错点。
- Markdown 是学习记录的源数据，`/leetcode/` 是对外展示页，两者要同步更新。
- 当前题一旦确认完成，立即同步完成记录并把下一道计划题切换为当前题，不等待每日定时任务；工作日 20:00 的自动化只负责兜底检查。

## 2026-10-19：Python 语法问答

- 当前 Python 语法聊天页面作为日常问答入口。
- 所有 Python 语法结论只整理到 `01_代码题/Python语法/Python语法问答.md`，不为每个问题新建 Markdown。
- 个人主页只维护一篇对应的普通文章；每次问答更新同一篇文章并同步到 GitHub，不新增文章、不设 Python 专属功能页或导航入口。
- 同类内容优先归并；示例保持最小可运行，同时记录常见误区和必要的版本差异。

## 2026-10-19：统一文章格式

- `00_学习档案与聊天迁移/文章模板.md` 是唯一的通用文章模板。
- 以后发布到个人主页的普通文章都使用该模板，保持标题、摘要、分类、标签和正文层级一致。
- 普通文章默认使用高对比度代码块，并在桌面端显示根据二级、三级标题生成、随滚动高亮的目录侧边栏；移动端隐藏侧边栏。
- 刷题记录、每日记录、计划和进度文件不属于普通文章，保留各自的专用格式。
