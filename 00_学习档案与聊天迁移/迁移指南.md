# 迁移指南

## 在新设备上恢复

```bash
git clone https://github.com/haozizizizi/haozizizizi.github.io.git
cd haozizizizi.github.io
```

然后在仓库根目录打开 AI 助手，发送：

> 请先完整阅读 `AGENTS.md` 和 `00_学习档案与聊天迁移`，总结我的学习背景、当前进度和下一步，然后继续工作。

## 在新账号上恢复

1. 确保新账号可读取本仓库。
2. 上传、克隆或打开整个仓库，不要只复制单篇笔记。
3. 使用上述恢复提示词。
4. 让新助手先报告它理解的当前状态，再继续新任务。

## 重要限制

原始聊天记录是否能迁移取决于聊天平台。本仓库保证的是“工作上下文可迁移”：目标、约定、学习成果、当前进度和下一步都存在 Git 中。
