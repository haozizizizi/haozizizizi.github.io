# 49. 字母异位词分组

- 日期：2026-10-19
- 链接：https://leetcode.cn/problems/group-anagrams/
- 题单：LeetCode 热题 100
- 难度：中等
- 类型：基线校准（历史状态待确认）
- 状态：已完成

## 核心思路

将每个字符串中的字符排序，把排序结果作为该字符串所属异位词组的统一键。字母异位词排序后会得到相同字符串，因此可以用哈希表把拥有相同键的原字符串收集到同一个列表中，最后返回哈希表中的所有分组。

## 代码

```python
class Solution:
    def groupAnagrams(self, strs: list[str]) -> list[list[str]]:
        str_map = {}
        res = []
        for word in strs:
            new_word = ''.join(sorted(word))
            if new_word not in str_map:
                str_map[new_word] = [word]
            else:
                str_map[new_word].append(word)
        for k, v in str_map.items():
            res.append(v)
        return res
```

## 复杂度

- 时间复杂度：`O(n × k log k)`，其中 `n` 是字符串数量，`k` 是字符串的平均长度；主要开销是逐个排序。更精确地说是 `O(Σ |sᵢ| log |sᵢ|)`。
- 空间复杂度：`O(n × k)`，哈希表的键和分组结果需要保存所有字符串相关内容；排序单个字符串还会产生 `O(k)` 的临时空间。

## 易错点

- `sorted(word)` 返回字符列表，不能直接作为字典键；需要先用 `''.join(...)` 转成字符串。
- 异位词的键必须采用统一规则生成，否则相同字符组成的字符串无法进入同一组。
