# 128. 最长连续序列

- 日期：2026-10-20
- 链接：https://leetcode.cn/problems/longest-consecutive-sequence/

- 类型：新题
- 状态：已完成

## 核心思路

先用集合去重。遍历每个数字时，把它视为一个待加入的连续区间，并分别用 `min_dict` 和 `max_dict` 记录区间边界。根据 `num - 1` 所在区间和 `num + 1` 所在区间是否存在，分为独立成段、向左扩展、向右扩展和连接左右两段四种情况；每次更新新区间的左右端点，并用端点之差计算当前长度。

## 代码

```python
class Solution:
    def longestConsecutive(self, nums: list[int]) -> int:
        nums_set = set(nums)
        min_dict = {}
        max_dict = {}
        max_len = 0

        for num in nums_set:
            if num in min_dict:
                continue

            if ((num - 1) in min_dict) and ((num + 1) in max_dict):
                min_dict[num] = min_dict[num - 1]
                max_dict[num] = max_dict[num + 1]
                min_dict[max_dict[num + 1]] = min_dict[num]
                max_dict[min_dict[num - 1]] = max_dict[num]
            elif (num - 1) in min_dict:
                min_dict[num] = min_dict[num - 1]
                max_dict[num] = num
                max_dict[min_dict[num - 1]] = max_dict[num]
            elif (num + 1) in max_dict:
                max_dict[num] = max_dict[num + 1]
                min_dict[num] = num
                min_dict[max_dict[num + 1]] = min_dict[num]
            else:
                max_dict[num] = num
                min_dict[num] = num

            max_len = max(max_dict[num] - min_dict[num] + 1, max_len)

        return max_len
```

## 复杂度

- 时间复杂度：平均 `O(n)`。建立集合需要 `O(n)`，之后每个不同数字只进行常数次集合和字典操作。
- 空间复杂度：`O(n)`。集合和两个边界字典最多保存与不同数字数量同阶的数据。

## 易错点

- 同时连接左右两个区间时，需要更新合并后最左端和最右端的边界信息，否则后续扩展会读到旧边界。
- 先转成集合可以去重，也使相邻数字判断的平均时间复杂度为 `O(1)`。
- 集合的遍历顺序不固定，因此四种合并情况必须都能正确维护区间边界。
