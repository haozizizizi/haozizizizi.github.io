## 核心思路

遍历网格中的每个位置。遇到值为 `"1"` 的陆地时，岛屿数量加一，并从该位置开始广度优先搜索。搜索过程中将陆地直接修改为 `"0"`，用输入网格自身作为访问标记，不再需要单独的 `visited` 矩阵。一次 BFS 恰好消除一个完整的岛屿连通块。

## 代码

```python
from collections import deque


class Solution:
    def numIslands(self, grid: List[List[str]]) -> int:
        n = len(grid)
        m = len(grid[0])
        result = 0
        q = deque()

        for l in range(n):
            for r in range(m):
                if grid[l][r] == "1":
                    q.append((l, r))
                    result += 1
                    while q:
                        i, j = q.popleft()
                        if (
                            i < 0
                            or i >= n
                            or j < 0
                            or j >= m
                            or grid[i][j] == "0"
                        ):
                            continue
                        grid[i][j] = "0"
                        q.append((i, j + 1))
                        q.append((i + 1, j))
                        q.append((i, j - 1))
                        q.append((i - 1, j))

        return result
```

## 复杂度

- 时间复杂度：`O(nm)`
- 空间复杂度：最坏 `O(nm)`，由 BFS 队列占用；相比上一版省去了 `O(nm)` 的 `visited` 矩阵。

## 易错点

- 这个解法会修改输入 `grid`；如果调用方还需要原网格，应保留 `visited` 矩阵或先复制网格。
- 出队后才将陆地改为 `"0"`，同一个陆地可能被相邻位置重复入队；不影响正确性，但也可在入队时立即改为 `"0"` 来减少重复。
- 队列中允许出现越界坐标，因此取出元素后要先判断边界，再访问 `grid[i][j]`。
- `m = len(grid[0])` 依赖题目保证网格非空；若用于通用函数，需要先处理空网格。
