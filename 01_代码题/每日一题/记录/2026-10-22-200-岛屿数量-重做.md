## 核心思路

遍历网格中的每个位置。遇到未访问的陆地时，岛屿数量加一，并从该位置开始广度优先搜索，将与它上下左右相连的全部陆地标记为已访问。一次 BFS 恰好消除一个完整的岛屿连通块。

## 代码

```python
from collections import deque


class Solution:
    def numIslands(self, grid: List[List[str]]) -> int:
        n = len(grid)
        m = len(grid[0])
        visited = [[False] * m for _ in range(n)]
        result = 0
        q = deque()

        for l in range(n):
            for r in range(m):
                if not visited[l][r] and grid[l][r] == "1":
                    q.append((l, r))
                    result += 1
                    while q:
                        i, j = q.popleft()
                        if (
                            i < 0
                            or i >= n
                            or j < 0
                            or j >= m
                            or visited[i][j]
                            or grid[i][j] == "0"
                        ):
                            continue
                        visited[i][j] = True
                        q.append((i, j + 1))
                        q.append((i + 1, j))
                        q.append((i, j - 1))
                        q.append((i - 1, j))

        return result
```

## 复杂度

- 时间复杂度：`O(nm)`
- 空间复杂度：`O(nm)`

## 易错点

- 出队后才标记 `visited`，同一个陆地可能被相邻位置重复入队；不影响正确性，但也可在入队时立即标记来减少重复。
- 队列中允许出现越界坐标，因此取出元素后要先判断边界，再访问 `visited[i][j]` 和 `grid[i][j]`。
- `m = len(grid[0])` 依赖题目保证网格非空；若用于通用函数，需要先处理空网格。
