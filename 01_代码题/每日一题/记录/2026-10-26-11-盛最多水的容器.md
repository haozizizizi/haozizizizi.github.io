## 核心思路

使用左右双指针从容器的最大宽度开始。当左侧高度不大于右侧时，移动左指针；否则移动右指针。因为容器高度受较短一侧限制，保留较短边只会让宽度继续减小，不可能得到更大面积；只有移动较短边才可能找到更高的边。

## 代码

```python
class Solution:
    def maxArea(self, height: list[int]) -> int:
        n = len(height)
        l = 0
        r = n - 1
        res = (r - l) * min(height[l], height[r])

        while l < r:
            if height[l] <= height[r]:
                l += 1
            else:
                r -= 1
            res = max(res, (r - l) * min(height[l], height[r]))

        return res
```

## 复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(1)`

## 易错点

- 应移动较短一侧；移动较高一侧时，高度仍受原短边限制，宽度却变小，不可能优于当前面积。
- 这份代码先计算初始左右边界的面积，循环中先移动指针再更新答案；如果改变执行顺序，要避免漏算最外层容器。
- 两边等高时移动任意一边都正确，这里选择移动左指针。
