# LeetCode 每日一题

目标：每天至少完成 1 道主题，优先攻克 LeetCode 热题 100 的中等题，通过固定复习日和间隔复习避免“做过即忘”。

- [`计划.md`](计划.md)：每周节奏、选题和间隔复习规则。
- [`热门100中等题队列.md`](热门100中等题队列.md)：68 道中等题主队列。
- [`进度.md`](进度.md)：当前任务、累计数据和复习队列。
- `记录/`：每道题的 Markdown 记录。

## 每日完成标准

1. 第一次尝试不看提示，中等题限时 30–40 分钟。
2. 通过后记录核心思路、复杂度和至少一个错误点。
3. 标注完成等级 A / B / C，由此计算下次复习日期。
4. 复习时必须从空白编辑器重写，不允许照抄旧代码。

## 完成等级

- **A**：30 分钟内独立通过，首次复习为 D+14。
- **B**：超时或只看了少量提示，首次复习为 D+7。
- **C**：看了题解、核心思路或未独立通过，首次复习为 D+3。
