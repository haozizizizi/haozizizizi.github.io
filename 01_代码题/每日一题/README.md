# LeetCode 每日一题

目标：周一到周五每天 1 题，周末休息。优先完成 LeetCode 热题 100 的中等题，并定期重做以前的题。

题目类型以 2026-10-19 之前的完整做题历史为准：以前做过的是复习题，以前从未做过的才是新题。本计划开始后的完成记录只用于统计本轮进度，不能单独决定题目类型。

- [`计划.md`](计划.md)：工作日安排和首月题目。
- [`热门100中等题队列.md`](热门100中等题队列.md)：68 道中等题主队列。
- [`进度.md`](进度.md)：当前任务、累计数据和复习队列。
- `记录/`：每道题的 Markdown 记录。

## 每题记录内容

- 核心思路
- 代码
- 时间与空间复杂度
- 易错点
