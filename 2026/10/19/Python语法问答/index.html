¶1. 创建 dict 和其他常用数据结构

¶dict：键值映射

# 空字典
d = {}
d = dict()

# 直接写键值对
user = {"name": "Tom", "age": 18}

# 从 (key, value) 序列创建
d = dict([("a", 1), ("b", 2)])

# 合并两个序列
d = dict(zip(["a", "b"], [1, 2]))

# 字典推导式
squares = {x: x * x for x in range(4)}

添加或更新元素使用 d["c"] = 3。不确定键是否存在时，可以使用 d.get("missing", 0) 提供默认值。

¶其他内置结构

数据结构空结构带初始值主要用途
list[] 或 list()[1, 2, 3]有序、可修改序列
tuple() 或 tuple()(1, 2, 3)有序、不可修改序列
setset(){1, 2, 3}元素去重、集合运算
dict{} 或 dict(){"a": 1}键值映射
 
from collections import Counter, defaultdict, deque

queue = deque()
groups = defaultdict(list)
counts = Counter("aab")

import heapq
heap = []
heapq.heappush(heap, 3)
smallest = heapq.heappop(heap)

¶2. 对字符串进行排序

sorted() 接收字符串后返回字符列表；需要字符串时使用 "".join()：

s = "dcab"

chars = sorted(s)                         # ['a', 'b', 'c', 'd']
result = "".join(sorted(s))               # "abcd"
reverse_result = "".join(sorted(s, reverse=True))  # "dcba"

忽略大小写排序：

s = "bAcD"
result = "".join(sorted(s, key=str.lower))  # "AbcD"

对字符串列表可以按字典序或长度排序：

words = ["pear", "apple", "fig"]

alphabetical = sorted(words)
by_length = sorted(words, key=len)

字符串不可变，也没有原地排序的 sort() 方法。默认排序使用 Unicode 顺序。

¶3. 遍历字典

user = {"name": "Tom", "age": 18}

# 遍历键
for key in user:
    print(key)

# 遍历值
for value in user.values():
    print(value)

# 同时遍历键和值（最常用）
for key, value in user.items():
    print(key, value)

# 同时取得序号、键和值
for index, (key, value) in enumerate(user.items()):
    print(index, key, value)

¶遍历时修改字典

可以修改已有键对应的值，但不要在遍历过程中直接新增或删除键，否则会抛出 RuntimeError：

scores = {"Alice": 80, "Bob": 90}

# 可以修改已有值
for name in scores:
    scores[name] += 1

# 删除键时，先遍历键的副本
for name in list(scores):
    if scores[name] < 85:
        del scores[name]

Python 3.7 起，字典遍历顺序保证与键的插入顺序一致。

¶易错点与边界

  • {} 创建的是空字典；空集合必须写成 set()。
  • 单元素元组必须保留逗号，例如 (1,)。
  • for x in dictionary 中的 x 是键，不是值。
  • 遍历期间不能改变字典大小；新增或删除键时应遍历副本或先记录待处理的键。
