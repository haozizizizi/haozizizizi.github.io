¶核心内容

¶1. 创建 dict 和其他常用数据结构

¶dict：键值映射

# 空字典
d = {}
d = dict()

# 直接写键值对
user = {"name": "Tom", "age": 18}

# 从 (key, value) 序列创建
d = dict([("a", 1), ("b", 2)])

# 合并两个序列
d = dict(zip(["a", "b"], [1, 2]))

# 字典推导式
squares = {x: x * x for x in range(4)}

添加或更新元素使用 d["c"] = 3。不确定键是否存在时，可以使用 d.get("missing", 0) 提供默认值。

¶其他内置结构

数据结构空结构带初始值主要用途
list[] 或 list()[1, 2, 3]有序、可修改序列
tuple() 或 tuple()(1, 2, 3)有序、不可修改序列
setset(){1, 2, 3}元素去重、集合运算
dict{} 或 dict(){"a": 1}键值映射
 
from collections import Counter, defaultdict, deque

queue = deque()
groups = defaultdict(list)
counts = Counter("aab")

import heapq
heap = []
heapq.heappush(heap, 3)
smallest = heapq.heappop(heap)

¶2. 对字符串进行排序

sorted() 接收字符串后返回字符列表；需要字符串时使用 "".join()：

s = "dcab"

chars = sorted(s)                         # ['a', 'b', 'c', 'd']
result = "".join(sorted(s))               # "abcd"
reverse_result = "".join(sorted(s, reverse=True))  # "dcba"

忽略大小写排序：

s = "bAcD"
result = "".join(sorted(s, key=str.lower))  # "AbcD"

对字符串列表可以按字典序或长度排序：

words = ["pear", "apple", "fig"]

alphabetical = sorted(words)
by_length = sorted(words, key=len)

字符串不可变，也没有原地排序的 sort() 方法。默认排序使用 Unicode 顺序。

¶3. 遍历字典

user = {"name": "Tom", "age": 18}

# 遍历键
for key in user:
    print(key)

# 遍历值
for value in user.values():
    print(value)

# 同时遍历键和值（最常用）
for key, value in user.items():
    print(key, value)

# 同时取得序号、键和值
for index, (key, value) in enumerate(user.items()):
    print(index, key, value)

¶遍历时修改字典

可以修改已有键对应的值，但不要在遍历过程中直接新增或删除键，否则会抛出 RuntimeError：

scores = {"Alice": 80, "Bob": 90}

# 可以修改已有值
for name in scores:
    scores[name] += 1

# 删除键时，先遍历键的副本
for name in list(scores):
    if scores[name] < 85:
        del scores[name]

Python 3.7 起，字典遍历顺序保证与键的插入顺序一致。

¶4. 创建和操作队列

算法题和普通单线程程序通常使用 collections.deque 实现队列。它在两端添加和删除元素的时间复杂度都是 O(1)：

from collections import deque

# 空队列
queue = deque()

# 带初始元素的队列
queue = deque([1, 2, 3])

¶常用操作

from collections import deque

queue = deque()

# 从队尾入队
queue.append(10)
queue.append(20)

# 查看队首和队尾
first = queue[0]   # 10
last = queue[-1]   # 20

# 从队首出队
value = queue.popleft()  # 10

# 长度和判空
size = len(queue)
if queue:
    print("队列非空")

# 双端队列操作
queue.appendleft(5)
value = queue.pop()

¶队列中存元组

队列可以存放元组等任意 Python 对象。坐标、状态等多个相关值通常打包成元组：

from collections import deque

queue = deque([(0, 0)])
queue.append((1, 2))

# 取出并解包
row, col = queue.popleft()
print(row, col)  # 0 0

# 单元素元组必须保留逗号
queue.append((1,))  # 元组
queue.append((1))   # 整数 1，不是元组

¶多线程队列

多个线程需要安全共享队列时，使用 queue.Queue：

from queue import Queue

queue = Queue()
queue.put(10)
value = queue.get()

算法题一般不需要线程安全，使用 deque 更直接。

¶5. 初始化和操作栈

Python 没有单独的内置栈类型。算法题和普通单线程程序通常使用 list，并把列表末尾作为栈顶：

# 空栈
stack = []

# 带初始元素的栈：3 是栈顶
stack = [1, 2, 3]

¶常用操作

stack = []

# 入栈
stack.append(10)
stack.append(20)

# 查看栈顶
top = stack[-1]  # 20

# 出栈
value = stack.pop()  # 20

# 长度和判空
size = len(stack)
if stack:
    print("栈非空")

# 清空栈
stack.clear()

append() 的均摊时间复杂度为 O(1)，pop() 和 stack[-1] 的时间复杂度为 O(1)。

¶栈中存元组

stack = []

stack.append((0, 0))
stack.append((1, 2))

row, col = stack.pop()
print(row, col)  # 1 2

¶其他栈实现

deque 也能作为栈使用；多个线程需要安全共享栈时，可以使用 queue.LifoQueue：

from collections import deque

stack = deque()
stack.append(10)
value = stack.pop()

from queue import LifoQueue

thread_stack = LifoQueue()
thread_stack.put(10)
value = thread_stack.get()

算法题通常直接使用 list，写法最简单。

¶示例与实践

下面的例子综合使用字典创建、get()、items() 和 sorted()，统计字符出现次数并按字符排序输出：

text = "banana"
counts = {}

for char in text:
    counts[char] = counts.get(char, 0) + 1

for char, count in sorted(counts.items()):
    print(char, count)

下面是队列存储坐标的 BFS 基本写法：

from collections import deque

queue = deque([(0, 0)])

while queue:
    row, col = queue.popleft()
    print(row, col)

    if row < 2:
        queue.append((row + 1, col))

下面用栈判断括号字符串是否合法：

def is_valid_brackets(text: str) -> bool:
    pairs = {")": "(", "]": "[", "}": "{"}
    stack = []

    for char in text:
        if char in "([{":
            stack.append(char)
        elif char in pairs:
            if not stack or stack.pop() != pairs[char]:
                return False

    return not stack


print(is_valid_brackets("([])"))  # True
print(is_valid_brackets("([)]"))  # False

¶易错点与边界

  • {} 创建的是空字典；空集合必须写成 set()。
  • 单元素元组必须保留逗号，例如 (1,)。
  • sorted(string) 返回字符列表，不是字符串；需要使用 "".join() 重新拼接。
  • for x in dictionary 中的 x 是键，不是值。
  • 遍历期间不能改变字典大小；新增或删除键时应遍历副本或先记录待处理的键。
  • 不要用列表的 pop(0) 频繁出队；它是 O(n)，而 deque.popleft() 是 O(1)。
  • 空队列调用 popleft() 或 pop() 会抛出 IndexError。
  • (value) 不是元组；单元素元组必须写成 (value,)。
  • 空栈调用 pop() 或访问 stack[-1] 会抛出 IndexError。
  • 列表模拟栈时应操作列表末尾；insert(0, value) 和 pop(0) 是 O(n)。

¶总结

选择数据结构时先判断是否需要键值映射、有序序列、去重、先进先出或后进先出。算法题中的队列优先使用 deque，栈通常使用 list；两者都能存储元组等对象。新的 Python 语法问题继续追加到本文件和同一篇主页文章中。
