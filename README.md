# Yuhao 的学习档案

这个仓库同时保存：

- 2021–2024 年的 Hexo 博客静态网页；
- 从 2026-10-19 重启的日常学习记录；
- 与 AI 助手协作所需的长期上下文和迁移记录。

## 目录

| 目录 | 用途 |
| --- | --- |
| `00_学习档案与聊天迁移` | 个人上下文、当前进度、决策与迁移指南 |
| `01_代码题` | 刷题记录、解法、错题与复习 |
| `02_论文阅读` | 论文笔记、方法拆解与实验结论 |
| `03_大模型知识` | LLM 原理、工程、产品与前沿进展 |
| `04_每日记录` | 每日学习日志 |
| `05_复盘与计划` | 周、月、季度复盘和下一阶段计划 |

## 从新设备或新账号继续

1. 克隆这个仓库。
2. 在仓库根目录打开 AI 编程助手。
3. 告诉它：“请先阅读 `AGENTS.md` 和 `00_学习档案与聊天迁移`，然后继续我的学习记录。”

平台的原始聊天记录可能绑定账号；这个仓库保存的是可持续使用的结构化上下文，不依赖特定账号。
